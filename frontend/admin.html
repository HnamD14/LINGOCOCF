👑 ADMIN SePay AUTO

🤖 Hướng dẫn kích hoạt tự động duyệt (SePay)

1Đăng ký miễn phí tại sepay.vn → Kết nối tài khoản ngân hàng
2Cài ngrok: ngrok http 8080 → Copy URL dạng https://abc.ngrok.io
3SePay Dashboard → Webhook → URL: https://abc.ngrok.io/api/payment/webhook/sepay
4Copy API Key của SePay → dán vào application.yml: sepay.webhook-secret: YOUR_KEY
5User chuyển khoản đúng nội dung mã đơn hàng → hệ thống tự duyệt trong vài giây! ✅
